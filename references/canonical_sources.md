## 1. Seed-URL Discipline

Every URL in this file is a **SKILL-SEED** (Part 0.4): a search target and fetch
starting point, never a citable fact. URL slugs on sebi.gov.in change with every
re-consolidation. Rules:

1. Populate the Phase 1 Canonical Source Table from what the **listing page shows
   today**, not from this catalog.
2. No URL enters a deliverable unless fetched live this session and confirmed to be
   the expected instrument (Phase 6 Gate 6).
3. If a seed URL 404s or redirects, that is expected staleness, not an error — find
   the current version via the listing page and flag this file for update in the
   delivery summary (corrections persist; see Phase 4).
